# 個人財務資產管理

> 帳戶、股票、保險、定期定額與股利紀錄

- **網址：** https://wangchiapin.github.io/All-MoneyBook/
- **Firebase 專案：** moneybook-50481
- **登入方式：** Email / 密碼
- **狀態：** 使用中
- **備註：** 資料在 `financeAssets` 等集合。與 `moneybook` 共用同一個 Firebase 專案。
- **雲端資料：** `financeAssets`（財務總覽）、`stockAssets`（股票管理＋美元匯率設定）、`insuranceAssets`（保險總覽）、`overviewMonthly`（全部資產一覽每月紀錄），每個帳號各一份
- **自動股價：** GitHub Action「每日更新收盤價」（`.github/workflows/prices.yml`）週一到週五 16:10 抓台股（上市、上櫃、ETF）當天收盤價與美股前一晚收盤價，存成 `data/prices.json`。美股代號列在 `data/us-symbols.txt`（一行一個）。股票管理的「🔄 更新股價」讀這個檔案，順便更新媽的永豐現值。可在 Actions 頁面手動按「Run workflow」立刻抓一次
- **全部資產一覽：** 合併財務總覽最新一欄（現金）、股票管理（股票）、保險總覽（保險）的現在狀態，可匯出 PDF。
  - **每月紀錄是「進入或按更新這一頁」時才會記下**（同一個月只留最新一筆）。整個月都沒打開過這一頁，那個月就沒有紀錄，之後也補不回來。
  - **月底股價：** Action 每個交易日都會把當天價格寫進 `data/month-end/當月.json`（同一個月一直覆蓋），所以檔案裡的價格是「那個月最後一次成功執行的價格」。月底剛好是週末或那天抓價失敗，就會是更早一天的價格。
  - 進入新的月份後，上個月會用這個價格 × 當時記錄的股數重算股票現值，顯示「比上月」增減。
- **美元匯率：** 標題列的「💵 美元匯率」是全站預設匯率，股票管理、全部資產一覽的美股都用它換算成台幣。財務總覽每一欄自己的匯率是「記錄那一天的匯率」，由你手動填，**不會**跟著全站匯率改變（這樣過去每一欄的台幣換算才不會變）。
