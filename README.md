# 個人財務資產管理

> 帳戶、股票、保險、定期定額與股利紀錄

- **網址：** https://wangchiapin.github.io/All-MoneyBook/
- **Firebase 專案：** moneybook-50481
- **登入方式：** Email / 密碼
- **狀態：** 使用中
- **備註：** 資料在 `financeAssets` 等集合。與 `moneybook` 共用同一個 Firebase 專案。
- **雲端覆蓋保護：** 登入時如果這台有「還沒上傳的修改」，不會被雲端直接蓋掉；雲端也被別台改過時會詢問，選用雲端前自動下載備份（`scripts/cloud-guard.js`）。標題列會寫出哪一塊同步失敗。
- **清空重置：** 先自動下載備份，清掉這個瀏覽器的資料（設定類保留）；登入中另外問要不要連雲端一起清（要輸入「清空雲端」）。
- **雲端資料：** `financeAssets`（財務總覽）、`stockAssets`（股票管理＋美元匯率設定）、`insuranceAssets`（保險總覽）、`overviewMonthly`（全部資產一覽每月紀錄），每個帳號各一份
- **自動股價：** GitHub Action「每日更新收盤價」（`.github/workflows/prices.yml`）週一到週五 16:10 抓台股（上市、上櫃、ETF）當天收盤價與美股前一晚收盤價，存成 `data/prices.json`。美股代號列在 `data/us-symbols.txt`（一行一個）。股票管理的「🔄 更新股價」讀這個檔案，順便更新媽的永豐現值。可在 Actions 頁面手動按「Run workflow」立刻抓一次
- **全部資產一覽：** 合併財務總覽最新一欄（現金）、股票管理（股票）、保險總覽（保險）的現在狀態，可匯出 PDF。
  - **每月紀錄是「進入或按更新這一頁」時才會記下**（同一個月只留最新一筆）。整個月都沒打開過這一頁，那個月就沒有紀錄，之後也補不回來。
  - **月底股價：** Action 每個交易日都會把當天價格寫進 `data/month-end/當月.json`（同一個月一直覆蓋），所以檔案裡的價格是「那個月最後一次成功執行的價格」。月底剛好是週末或那天抓價失敗，就會是更早一天的價格。
  - 進入新的月份後，上個月會用這個價格 × 當時記錄的股數重算股票現值，顯示「比上月」增減。
- **美元匯率：** 標題列的「💵 美元匯率」是全站預設匯率，股票管理、全部資產一覽的美股都用它換算成台幣。財務總覽每一欄自己的匯率是「記錄那一天的匯率」，由你手動填，**不會**跟著全站匯率改變（這樣過去每一欄的台幣換算才不會變）。
- **對帳單匯入：** 標題列「📥 匯入對帳單」選 PDF 對帳單，在自己的裝置上讀取（PDF 不會上傳），確認後寫進股票買進／賣出／借券收入、財務總覽的銀行餘額。讀取程式是 `scripts/stmt-parsers.js`，用對帳單自己印的總計／餘額自我核對。目前認得：國泰證券、富邦證券、永豐金證券、台北富邦銀行、國泰世華銀行、第一銀行、永豐銀行、台新銀行、將來銀行、華南銀行、中國信託、台灣銀行、高雄銀行、玉山銀行、王道銀行、台北富邦信用卡、國泰世華信用卡、公教退撫儲金、私校退撫儲金。其他家的會顯示「認不出」。
  - 永豐金證券的資料寫到「媽的永豐」；配息用股票代號對持股。
  - 王道銀行：臺幣活存、外幣活存、外幣定存每一筆各算一個帳戶；明細沒有逐筆餘額，餘額是用期末餘額往回推的，沒辦法自動核對有沒有漏讀，要自己對照筆數。
  - 圖片型 PDF（掃描檔）會自動用 OCR 讀，第一次使用比較慢。
  - 這個檔也被 `huimoney` 網站直接載入使用，所以改解析檔會同時影響兩邊。
- **📬 自動收到的對帳單：** 另一個私人倉庫的自動程式（`moneybook-stmt-bot`）會從 Gmail 拿對帳單 PDF、讀好，放進雲端 `stmtPending`。標題列的「📬 自動收到的對帳單」按鈕有東西時才出現，勾選後送進原本的確認畫面，寫入後從清單拿掉（`scripts/stmt-pending.js`）。自動程式只會放進清單，一定要在這裡按寫入才會改到帳。
- **Google 試算表同步與每週資產週報（`apps-script/`）：** `finance-sync.gs` 把上面四份雲端資料同步到 Google 試算表；`weekly-report.gs` 每週日晚上 8 點（台北時間）寄「全部資產一覽」週報。週報收件人不寫在程式裡，要到 Apps Script「專案設定 → 指令碼屬性」新增 `REPORT_EMAIL`。細節與「改了哪些欄位就要同步改腳本」見 `apps-script/README.md`。腳本只是存檔備份，要貼到 Apps Script 才會生效。
- **資料夾說明：** `index.html` 是主頁；`scripts/` 放各分頁的功能程式（財務、股票、保險、全部資產一覽、對帳單、雲端覆蓋保護、手機版等）；`styles/` 放樣式；`data/` 放自動抓的股價（`prices.json`、`month-end/`、`us-symbols.txt`）；`.github/` 放每日更新股價的排程與抓價程式（`scripts/fetch_prices.py`）。
